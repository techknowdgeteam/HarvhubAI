HARVHUB AI - FRESH VPS INSTALLATION

1. Copy ONLY HarvHubAI.vbs to the new VPS.
2. Double-click HarvHubAI.vbs and approve the Windows administrator prompt.
3. A visible HarvHub AI - Installer window displays the GitHub ZIP download, extraction, validation and Python preparation.
4. When bootstrap completes, the normal HarvHub AI builder window opens, followed by the manager.

Do not launch the Python builder directly on a fresh VPS. The VBS launcher must run first so GitHub is downloaded and validated before Python setup.

GitHub repository: https://github.com/techknowdgeteam/HarvhubAI
Installed root: C:\xampp\htdocs\harvhubAI

Fresh VPS without Python: HarvHubAI.vbs opens a visible CMD bootstrap, installs/verifies Python, then opens the desktop build window.
MetaTrader 5: automatic install is verified by terminal64.exe; if automatic mode fails, the official setup wizard opens for the exact HarvHub AI MT5 folder.
