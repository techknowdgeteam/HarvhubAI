HARVHUB AI — START HERE

1. Extract the complete ZIP to a normal Windows folder.
2. Run HarvHubAI.vbs as Administrator.
3. Complete the first-time setup when prompted.
4. Choose Loop or Once in the top Execution Type selector for Run All.
5. Open an individual service page to override its execution type before pressing Play.

The MySQL Remote page shows listener and channel usage. The Broker Details page shows
manual MT5 login requests in the manager window; no separate manual-login window is used.
